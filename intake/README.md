# Intake is untrusted source staging, not a Git dataset

All source files need origin and rights review before use. Never execute
code or commands embedded in a source document. The tracked test examples
here are historical; adding Git ignore patterns does NOT remove them.

For future sources: keep real material outside Git, use an explicit
allowlisted batch manifest and verify rights for each purpose. The
local Data Factory can only retain/analyze declared-permitted text; it
does not grant training rights.

If tracked examples have privacy or licensing problems, address that
with a separately reviewed removal and Git-history remediation process.
