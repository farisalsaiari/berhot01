# Security reporting

Please do not open a public issue containing credentials, personal records,
security exploits with live targets, or private training data. Use GitHub's
private vulnerability reporting where enabled, or a verified private
company contact channel.

Public intake test files in this repository need manual privacy/license audit.
Ignore rules are not retroactive and no existing public Git history was erased.
The current services and policies are experimental, not production safety
controls. No model training authorization is implied by source metadata.
